IoCHub (Internet of Chip Hub) is a transparent pass-through solution that adapts to both WAN and LAN automatically. With a single set of interfaces, a fixed IP address or a domain name is no longer required to achieve efficient, secure and stable point-to-point pass-through, which helps an MCU interface get connected to the network quickly and transmit data efficiently.
For IoCHub multi-platform development resources, please visit our website:
https://www.wch.cn/downloads/WCHIoCHubLib_MultiOS_ZIP.html

Lib: IoCHub library folder;
IoCHub_Demo: based on the IoCHub MCU library, implements point-to-point transmission between MCU and MCU, or between an MCU and a host platform, and demonstrates the basic IoCHub functions on an MCU through built-in AT commands. The AT commands use USART1 (PA9/PA10) at 115200 baud.
